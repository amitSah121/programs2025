The whole app has two tabs, 
a) note matrix
b) project main tab


1) note matrix
- It should display a list of created notes in this project at the sidebar, the structure can be of a folder structure that contains files kinda approach , meaning each folder can have multiple folders or files, and each file represent one sequence of notes
- each file can have different interval of total bars, if major or any other kind of display preferred, number of notes in a single cell( for playing faster softer notes like 2 notes a bar kinda ) and type of lageto/portamento/glissando to be used
- each cell can have its own starting and ending point and can span through multiple bars, can have its own velocity, and volume
- also, there are three modes of making notes , 
a) either by clicking and adjusting individual cells , 
b) or by direct note editing like ( if c-major scale selected then on that basis will the notes cmaj, cmin, dmaj, dmin, d7 .... be) and such that a single row can be filled directly
c) or by adding row basis, bars are fixed first then on the basis of how many rows are required its adjusted and then each column is programmed accordingly, e.g. 1st column can have c3, E3, G3 in 1st , 2nd and 3rd row, representing cmajor, and each cell has the ability to adjust volume and velocity as well starting and ending of notes and can span to other bars. // not necessary , with free floating noteWrite and row adder I can write this as well

======================

 Final DAW Feature Checklist (File Structure + Conventions)
🎼 Note Matrix System
 File/folder-based note containers per project

 Custom number of bars, rows, and cell-wise velocity/volume/start/end

 Supports multiple modes: manual, scale, grid

 Per-file synth + effects chain

 JSON format for notes + layout (✅ complete)

🧩 Effect Chains
 Source instrument (src) per chain with parameters

 Serial + parallel effects

 Effects have IDs and parameters for automation

 Chain belongs to a timeline row

 Editable UI controls for any param (✅ complete)

⏱ Timeline System
 All notes rendered to .wav via Tone.Offline

 Timeline tracks can include both note and sample files

 Tracks have gain, start, duration, group, etc.

 Groups affect UI-based automation/mixing/organization

 UI shows audio waveforms only (✅ complete)

📈 Automation System
 SVG.js-based editable curves

 Curves can target synth or effect or external file

 Support for parameter grouping (one curve → multiple targets)

 Stored in per-project automation/ folder

 Duration, resolution, loop, and precision fully controllable (✅ complete)

🔄 Undo/Redo System
 JSON-based action log with patches or diffs

 Efficient storage (delta-based, not whole state)

 Timeline + note + chains fully restorable

 Stack tracker in history/index.json (✅ complete)

📂 File API System
 Read/write/create/copy/move/delete any file in res/

 /api/allFiles for recursive project listing

 Locked within res/ sandbox for safety

 File properties for renaming, metadata, etc. (✅ complete)
